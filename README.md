# Netflix Style Web Application

A responsive **Netflix-style UI clone** built using HTML and CSS, showcasing modern layout design and front-end styling techniques.
This project focuses on replicating the look and feel of Netflix’s homepage.

---

##  Features

* Netflix-inspired UI design
* Responsive layout (works on different screen sizes)
* Movie/series sections layout
* Clean and modern styling
* Hover effects and UI interactions

---

## Tech Stack

* HTML
* CSS
